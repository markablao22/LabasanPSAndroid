# LabasanPSAndroid

## Updated water elevation logbook

The updated browser version is available at [`index.html`](./index.html).

Features:
- Monthly Labasan Pumping Station water elevation logbook
- 24-hour rows with `12MN` and `12NN` labels
- Local browser storage for readings
- Copy/paste daily readings from spreadsheet data
- Reset one selected date without clearing other dates
- Clear all entries for the selected month
- Print / Save PDF

Open `index.html` in a browser. This commit adds the updated web logbook source; it is not a compiled APK.
